CSS

Cascata, dimensionamento, layout e responsividade.

Conceitos essenciais

Seletores e cascata

Classes selecionam elementos reutilizáveis. Entre regras normais do mesmo autor e da mesma camada, a maior especificidade vence. Se a especificidade for igual, vence a declaração posterior.

Modelo de caixa

Cada elemento tem conteúdo, padding, borda e margem. Com box-sizing: border-box, o width inclui padding e borda. Margens ficam fora da caixa.

Flexbox e Grid

Flexbox organiza itens em um eixo principal e outro transversal. Grid define linhas e colunas ao mesmo tempo. Use gap para espaçar itens nos dois layouts.

Responsividade e estados

Use unidades flexíveis, limites de largura e media queries quando o conteúdo precisar de uma mudança de layout. :focus-visible marca o foco para navegação por teclado. Garanta contraste e legibilidade.

Cards responsivos

CSS
* {
  box-sizing: border-box;
}

.grade {
  display: grid;
  /* Cria colunas conforme a largura disponível. */
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
  gap: 1rem;
}

.cartao {
  padding: 1rem;
  border: 1px solid #526477;
  border-radius: 0.75rem;
}

a:focus-visible {
  outline: 3px solid #005cc5;
  outline-offset: 3px;
}

Aplique .grade ao contêiner e .cartao aos filhos. As colunas se reorganizam quando falta espaço e o limite min(100%, 16rem) evita impor 16rem em telas menores.

Exercícios de revisão

Tente resolver antes de abrir a resposta.

Com width de 200px, padding de 16px e borda de 2px, qual a largura do conteúdo usando border-box?

Resposta. 200 − 32 − 4 = 164px.

Se duas regras .cartao definem a mesma propriedade no mesmo contexto, qual vence?

Resposta. A última, pois ambas têm a mesma especificidade.
