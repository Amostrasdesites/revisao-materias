Conceitos essenciais

Compilação e tipos

O compilador traduz o código e produz um executável após a ligação. Use int para inteiros, double para valores de ponto flutuante e char para caracteres. Em C, 5 / 2 vale 2, enquanto 5.0 / 2 vale 2.5.

Controle de fluxo

if e else escolhem um caminho. for é útil para percorrer posições de um vetor. while repete enquanto a condição for verdadeira. Confundir = com == muda uma comparação em atribuição.

Vetores e strings

Um vetor com n posições aceita índices de 0 a n − 1. Uma string em C é uma sequência de char terminada por '\0'. Reserve espaço para o terminador ao dimensionar o vetor.

Funções e ponteiros

Argumentos são passados por valor. Para alterar uma variável do chamador, passe seu endereço com & e acesse o objeto pelo ponteiro com *. Ao receber um vetor em função, passe também seu tamanho.

Estruturas e memória

struct reúne campos relacionados. malloc reserva memória dinâmica e pode retornar NULL. Libere com free quando terminar e evite acessar memória fora dos limites ou depois de liberá-la.

Média de um vetor

C
#include <stdio.h>
#include <stddef.h>

double media(const int notas[], size_t quantidade) {
    double soma = 0.0;
    for (size_t i = 0; i < quantidade; i++) {
        soma += notas[i];
    }
    return soma / quantidade;
}

int main(void) {
    int notas[] = {7, 8, 9};
    // sizeof funciona aqui, onde notas ainda é um vetor.
    size_t quantidade = sizeof notas / sizeof notas[0];
    printf("Media: %.1f\n", media(notas, quantidade));
    return 0;
}

Saída: Media: 8.0. Compile com gcc -std=c17 -Wall -Wextra media.c -o media. A função pressupõe quantidade maior que zero e recebe o tamanho real calculado em main.

Exercícios de revisão

Tente resolver antes de abrir a resposta.

Quais são os índices válidos de int valores[5]?

Resposta. De 0 a 4. Acessar valores[5] ultrapassa o vetor.

Por que usar double para soma?

Resposta. Dividir uma soma double por um inteiro gera divisão em ponto flutuante, preservando a parte fracionária.
