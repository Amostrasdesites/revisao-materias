Conceitos essenciais

Tipos e conversões

int, float, str e bool representam valores diferentes. input devolve texto, então converta quando precisar calcular. / faz divisão real e // arredonda o quociente para baixo.

Controle de fluxo

A indentação delimita blocos. Use if, elif e else para decisões. for percorre um iterável. range(3) gera 0, 1 e 2. while repete enquanto a condição se mantém verdadeira.

Coleções

Listas são ordenadas e mutáveis. Tuplas são ordenadas e imutáveis em sua estrutura. Dicionários associam chaves a valores. Conjuntos armazenam elementos distintos e ajudam em testes de pertinência.

Funções, módulos e classes

def declara uma função e return entrega um valor ao chamador. import reutiliza módulos. Uma classe reúne comportamento e estado, e self referencia a instância que recebe a chamada.

Arquivos e exceções

Use with open(..., encoding='utf-8') para fechar arquivos automaticamente ao sair do bloco. Capture exceções específicas, como ValueError ao converter texto inválido.

Média com validação

Python
def media(notas):
    if not notas:
        raise ValueError("Informe pelo menos uma nota.")
    return sum(notas) / len(notas)

dados = ["7.5", "8.0", "9.0"]
try:
    # Converte cada texto, produzindo uma nova lista.
    notas = [float(item) for item in dados]
    print(f"Média: {media(notas):.2f}")
except ValueError as erro:
    print(f"Dados inválidos: {erro}")

Saída: Média: 8.17. A compreensão percorre a lista, a função devolve a média e o bloco except trata uma conversão inválida ou uma lista vazia.

Exercícios de revisão

Tente resolver antes de abrir a resposta.

Como contar ocorrências de uma palavra em um dicionário?

Resposta. Use contagem[palavra] = contagem.get(palavra, 0) + 1 para começar em zero quando a chave ainda não existe.

Qual a diferença entre print e return?

Resposta. print escreve na saída. return encerra a função e entrega um valor para quem a chamou.
