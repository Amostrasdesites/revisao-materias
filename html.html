Conceitos essenciais

Documento e semântica

DOCTYPE ativa o modo padrão do navegador. O head contém metadados e referências. O body contém o conteúdo. Use main para o conteúdo principal, nav para navegação e uma hierarquia de títulos que reflita a organização.

Links e mídia

Use a com href para navegar e button para ações. Imagens informativas precisam de texto alternativo que cumpra o mesmo propósito. Use alt vazio em imagens puramente decorativas.

Formulários

Associe label e input via for e id. O atributo name identifica o campo no envio. type='email' e required ajudam na validação do navegador. Um servidor deve validar os dados novamente ao recebê-los.

Listas e tabelas

Use ul para itens sem ordem e ol para sequências. Use tabelas para dados tabulares, com caption para contextualizar e th com scope para cabeçalhos.

Formulário semântico

HTML 
<!doctype html>
<html lang="pt-BR">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Lista de estudo</title>
</head>
<body>
  <main>
    <h1>Cadastro de estudo</h1>
    <!-- O label dá nome acessível ao campo. -->
    <form method="get">
      <label for="email">Seu e-mail</label>
      <input id="email" name="email" type="email" required>
      <button type="submit">Enviar</button>
    </form>
  </main>
</body>
</html>

Salve como index.html e abra no navegador. O exemplo demonstra o envio para a própria página via GET. Use um e-mail fictício, pois o valor aparece na URL.

Exercícios de revisão

Tente resolver antes de abrir a resposta.

O que ocorre se o input tiver id, mas nenhum name?

Resposta. O label ainda pode funcionar, mas o valor do campo não entra nos dados enviados pelo formulário.

Qual elemento usaria para abrir outra página?

Resposta. Um link com <a href="...">.
