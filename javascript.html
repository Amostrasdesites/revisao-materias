Conceitos essenciais

Tipos e operadores

Use const para vínculos sem reatribuição e let quando houver reatribuição. const ainda permite alterar propriedades de um objeto. === compara sem coerção de tipos. Number converte texto numérico e Number.isFinite valida o resultado.

Funções e coleções

Arrays guardam listas ordenadas e objetos guardam propriedades. map transforma elementos, filter seleciona elementos e reduce acumula um resultado. Uma função pode receber ou retornar outras funções.

DOM e eventos

querySelector encontra o primeiro elemento correspondente. addEventListener associa uma função a um evento. textContent atualiza texto sem interpretá-lo como HTML. Em formulários, preventDefault cancela o envio padrão quando você vai tratar o evento.

Assincronismo e JSON

Uma Promise representa o resultado futuro de uma operação. await espera a resolução dentro de uma função async. Com fetch, verifique response.ok antes de ler JSON e trate falhas de rede com try/catch.

Contador de sessões

JavaScript 
// HTML necessário, antes de carregar o script:
// <button id="somar">Registrar sessão</button>
// <p id="total" aria-live="polite">Sessões: 0</p>

const botao = document.querySelector("#somar");
const total = document.querySelector("#total");
let sessoes = 0;

botao.addEventListener("click", () => {
    sessoes += 1;
    total.textContent = `Sessões: ${sessoes}`;
});

Insira os elementos indicados e coloque o script depois deles ou carregue um arquivo externo com defer. Cada clique aumenta a variável e atualiza o parágrafo.

Exercícios de revisão

Tente resolver antes de abrir a resposta.

O que retorna [2, 5, 8].filter(n => n > 4)?

Resposta. [5, 8]. filter mantém os elementos que satisfazem a condição.

Por que checar response.ok no fetch?

Resposta. Uma resposta HTTP 404 ou 500 pode resolver a Promise normalmente. response.ok identifica respostas na faixa de sucesso 200–299.
